# Coding Fundamentals — Starting From Zero

Welcome! This is a slow, no-pressure path back into coding. You don't need to
remember anything from school — we start from the very beginning and build
up one small step at a time.

## Why learn to code at all?

Almost everything around you runs on instructions someone wrote for a
computer — apps, websites, bank transfers, traffic systems. Coding is
learning to write those instructions yourself. Two reasons it's worth doing:

- **You can build things**, not just use them — a tool, an app, a website.
- **It trains a way of thinking** — taking a big, messy problem and breaking
  it into small, clear steps — that's useful far beyond computers.

## Why "bits" matter

A computer only ever understands one thing: on or off, 1 or 0. That single
1-or-0 is called a **bit**. Everything you see on a screen — text, photos,
videos — is, underneath, a huge pile of these bits. You won't write in 1s
and 0s day to day, but knowing that's what's really happening makes the
rest of programming feel a lot less like magic.

See [`curriculum/01-computers-and-bits.md`](curriculum/01-computers-and-bits.md)
for the full, gentle explanation.

## The roadmap (go at your own pace)

Each module builds on the last. Don't move on until the current one feels
comfortable — there's no clock running.

1. **[How computers "think"](curriculum/01-computers-and-bits.md)** — bits,
   bytes, and why a program is just a list of steps.
2. **[What is programming?](curriculum/02-what-is-programming.md)** — what a
   programming language actually is, and why we'll use Python.
3. **[Your first program](curriculum/03-your-first-program.md)** — writing
   and running actual code for the first time.
4. Variables, decisions (if/else), and loops — introduced one at a time
   after step 3, once you're ready.
5. Small, fun mini-projects that use only what you've already learned.

When you're ready for the next lesson, just say so and we'll add it.
