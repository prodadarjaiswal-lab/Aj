# Lesson 2: What Is Programming?

## A program is just instructions

Imagine explaining to someone, step by step, exactly how to make a cup of
tea — not "make tea," but every tiny step: boil water, get a cup, put in a
tea bag, pour water, wait, remove tea bag, add milk if wanted. That level of
precise, ordered instruction is exactly what a computer program is — except
the instructions are for a computer instead of a person, and the computer
will follow them *exactly*, without guessing what you meant.

**Programming** is the act of writing that list of instructions in a form a
computer can follow.

## Why we need "programming languages"

Computers ultimately only understand bits (from Lesson 1) — streams of 1s
and 0s. Writing directly in 1s and 0s would be painfully slow and easy to
get wrong. So people created **programming languages**: readable, more
human-friendly ways to write instructions, which get automatically
translated into the 1s and 0s a computer needs.

There are many programming languages (Python, JavaScript, C, Java, and
others) — think of them like different human languages that can each
describe the same idea, with their own grammar and style.

## Why we'll start with Python

We're going to use **Python** for these lessons because:

- Its instructions read almost like plain English.
- It doesn't require a lot of extra setup or symbols to get started.
- It's one of the most widely used languages today, for everything from
  small scripts to large-scale software.

You don't need to install anything yet — we'll do that together right
before Lesson 3, [Your first program](03-your-first-program.md), where
you'll write and run real code for the first time.
