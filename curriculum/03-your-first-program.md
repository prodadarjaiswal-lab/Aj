# Lesson 3: Your First Program

This is the lesson where you actually write and run code. Take it slow —
there's nothing to memorize, just something to try.

## Step 1: Get Python running

You have two easy options — pick whichever feels less intimidating:

- **Online, no install (easiest to start with):** go to
  [replit.com](https://replit.com) or [python.org/shell](https://www.python.org/shell/)
  in your browser, choose Python, and you'll get a box where you can type
  code and run it immediately.
- **On your own computer (for later):** install Python from
  [python.org/downloads](https://www.python.org/downloads/). We can walk
  through this together whenever you're ready for it.

For now, the browser option is enough.

## Step 2: Write one line

Type exactly this into the Python box and run it:

```python
print("Hello, world!")
```

You should see `Hello, world!` appear as output.

## What just happened?

- `print(...)` is an **instruction**: "show this on the screen."
- `"Hello, world!"` is the **text** you're telling it to show — the quote
  marks tell Python "this is just text, not a command."
- Together, `print("Hello, world!")` is one complete instruction, and
  Python carried it out exactly as written — no more, no less. This is
  the "precise and literal" idea from Lesson 1 in action.

Every programmer's very first program is traditionally exactly this — you
just wrote it too.

## Try it yourself

Change the text inside the quotes to say something else — your name, a
message, anything — and run it again. Notice: whatever you put between the
quotes is exactly what gets shown. Nothing is guessed or assumed.

When you're comfortable with this, let's move on to **variables** — how to
get a program to remember and reuse information, instead of just printing
fixed text. Just say you're ready and we'll add that lesson.
